# React E-Commerce Website

A responsive E-Commerce web application built using React.js. Users can browse products, search items, and filter products through a clean and user-friendly interface.

## Features

- Product Listing
- Product Search
- Category Filtering
- Responsive Design
- API Integration

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
